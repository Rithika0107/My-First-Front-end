# 🏛️ Heritage for Kids – Heritage Learning Platform

## 📌 About the Project

**Heritage for Kids** is an interactive web-based learning platform designed to help children discover and learn about India's historical monuments in an engaging and enjoyable way.

The platform allows children to search for popular heritage sites, explore historical information, and test their knowledge through interactive quizzes.

It provides a simple, colourful, and user-friendly interface that makes learning about history more interesting for young learners.

## ✨ Features

* 🔍 **Heritage Site Search:** Search for historical monuments by name.
* 📸 **Photo Upload:** Upload monument images (demonstration feature).
* ⭐ **Popular Heritage Sites:** Quickly explore featured monuments.
* 📖 **Historical Information:** Learn about the history and significance of monuments.
* 📝 **Interactive Quizzes:** Answer questions and check your knowledge.
* 🎨 **Kid-Friendly Interface:** Simple and attractive design.
* 🔔 **Interactive Messages:** Get welcome messages and feedback.

## 🏛️ Currently Available Heritage Sites

1. **Brihadeeswarar Temple**

   * Built by Raja Raja Chola I.
   * Famous for its magnificent Chola architecture.

2. **Red Fort**

   * Constructed by Mughal Emperor Shah Jahan.
   * Served as a major residence of Mughal rulers.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder in Visual Studio Code.

3. Make sure the following files are available:

   * index.html
   * style.css
   * script.js

4. Start the website using Live Server or configure the Chrome debugger.

5. Open the website in your browser.

**Note:** The provided Chrome debugging configuration uses `http://localhost:8080`. Ensure your local development server is running on port 8080.
